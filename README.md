# OneKeyMinerChainableVisuals-Continued
一键连锁：可视化模组的续作

**OneKeyMiner 连锁可视化续作** · 已获原作者许可

原模组：https://www.mcmod.cn/class/22233.html

原版解决“看不见可连锁对象”；续作重点改进**准确性、稳定性、主模组联动和反馈**。

| 项目 | 原版 | 续作 |
|---|---|---|

| 准星框 | 原版白框 | 按住连锁键时显示**亮绿色小框**，颜色写死 |
| 主模组联动 | 视觉层独立估算 | 数量/距离/斜向规则自动跟随主模组，含服务器策略 |
| 降级提示 | 无 | 主模组 <1.6.8 提示“本地预判”；预览失败 2 秒自动降级并提示 |
| 交互预览 | 被动高亮 | 按住 `V` 主动预览可交互方块链 |
| 数量 HUD | 无 | 显示“可连锁 N 个方块”；本地预判标注“（估算）” |
| 粒子/音效 | 无 | 粒子连线、递进提示音，默认关，纯本地 |

## 功能

### 连锁高亮
- 按住主模组连锁键，显示整组可连锁方块轮廓。
- 两种画法：统一外轮廓 / 逐方块线框。
- 超过 1500 方块自动切统一外轮廓，聊天栏提示一次。
- 增强描边光晕（默认关）。
- 隔墙显示（需开启自定义渲染管线）。
- 准星绿色小框，取代原版白框。
- 防闪烁/防残影：小框每帧跟随准星；整组轮廓只在主模组发布对应当前指向和朝向的新结果后显示。

### 交互连锁预览
- 按住 `V`，本地估算门、活板门、栅栏门、按钮、拉杆、箱子、木桶、熔炉及带方块的实体类方块。
- 交互色高亮，默认近白青色，HUD 数字同色。

### 剪羊毛高亮
- 按住连锁键 + 手持剪刀 + 准星对准可剪羊 → 高亮附近羊群，默认 24 格。

### HUD
- 准星旁显示可连锁数量。
- 主模组驱动时附带形状名；本地预判时明确标注“（估算）”。

### 粒子与音效
- 粒子连线：默认关，密度可调。
- 递进提示音：默认关，按连锁数量播放竖琴上行音阶 + 结尾“叮”，纯本地，不发包。

### 主模组联动
- 数量、距离、斜向规则自动跟随主模组，包括服务器下发策略。
- 设置页顶部实时显示主模组当前生效值。
- 主模组太旧：进世界提示“当前为本地预判”。
- 预览连续失败 2 秒：自动降级为本地预判并提示，换世界/维度后自动重试。

### 兼容性
- 自定义渲染管线开关：关闭后改用原版线渲染层，减少渲染冲突。
- 旧版本存档设置默认值一次性自动迁移。

## 按键

| 按键 | 默认 | 作用 |
|---|---|---|
| 设置 | `N` | 打开配置页：高亮 / 颜色 / 连线粒子 / HUD 与音效 |
| 交互预览 | `V`（按住） | 显示交互连锁预览 |
| 连锁键 | 复用主模组 `` ` `` | 本模组不注册新键 |

所有按键可在原版“控制”中改绑。

---

## 说明

- 纯客户端视觉模组；多人游戏中数量、距离、斜向规则以主模组/服务器策略为准。
- 建议搭配 OneKeyMiner ≥ 1.6.8；低于该版本会自动降级为本地预判并提示。
- 如遇渲染冲突，可在设置中关闭自定义渲染管线。
